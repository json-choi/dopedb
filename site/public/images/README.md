# Galaxy artwork

`galaxy-photographic-v2.webp` is original AI-generated photographic-style artwork
for DopeDB's landing background. It is not an astronomical observation or a
scientifically accurate reconstruction of the Milky Way.

Art direction: an oblique spiral galaxy with branching opaque brown dust lanes,
dense warm ivory starlight, fragmented blue-white outer arms, restrained natural
colors, and darker space to the left for existing page copy. No text or branding
is baked into the image.

The built-in image generation tool produced the 1672 × 941 source. The web asset
uses quality-95 WebP encoding without resizing or changing the composition.
The same asset is the non-WebGL fallback and the GPU texture source.
