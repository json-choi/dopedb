# site/public

## Purpose
Static assets served at the site's root path: favicons/app icons, dated
product screenshots used on the landing page, Google site-verification, and
`llms.txt`. Everything here is served verbatim by Next.js; there is no build
step for this directory itself.

## Key Files
| File | Description |
|------|-------------|
| `favicon.ico` / `favicon.svg` / `favicon-48x48.png` | Site favicons, generated from `assets/brand/dopedb-icon.svg` (see `assets/AGENTS.md`). |
| `apple-touch-icon.png` / `icon-192.png` / `icon-512.png` | Home-screen / PWA-style icons, generated from the same brand source. |
| `oauth-logo-120.png` | Logo uploaded to external OAuth consoles (Google/GitHub); replacing it here does not update what those consoles already display. |
| `dopedb-desktop-0.4.21.png` / `dopedb-desktop-0.4.21-ko.png` | Dated desktop-app screenshots (English/Korean) embedded in the landing page; historical records of that version, not living assets to redraw over. |
| `google3c3733fc1fdd3ce8.html` | Google Search Console site-verification file. |
| `llms.txt` | Machine-readable summary for AI crawlers/agents, aligned with the crawler allow-list in `../app/robots.ts`. |

## For AI Agents

### Working In This Directory
- Do not overwrite a version-numbered screenshot (`dopedb-desktop-0.4.21*.png`) in place; a new UI needs a newly captured, newly named screenshot and an updated reference from `../app/HomeDemoShowcase.tsx` or `homeContent.ts`.
- Regenerate icons only via `pnpm icons` from `assets/brand/dopedb-icon.svg` (see `assets/AGENTS.md`); do not hand-edit a generated icon file here.
- `llms.txt` and `../app/robots.ts`'s crawler allow-list should stay consistent when either changes.

### Testing Requirements
- `pnpm icons --check` verifies generated assets here are in sync with the brand source; no other automated check targets this directory.

### Common Patterns
- Filenames that embed a version number (`dopedb-desktop-0.4.21.png`) are treated as immutable historical records, matching the convention in `assets/brand/README.md`.

## Dependencies

### Internal
- Generated by `scripts/generate-icons.py` from `assets/brand/dopedb-icon.svg`; referenced by `../app/layout.tsx`, `../app/HomeDemoShowcase.tsx`, `../app/robots.ts`, `../app/sitemap.ts`.

### External
- None; static files only.
