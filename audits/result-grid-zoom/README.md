# 조회 결과 확대 및 기본 크기 복귀

로컬 macOS QA 앱에서 제품 소유 Demo SQLite의 orders 표를 촬영했다.
개인 데이터베이스나 자격 증명은 포함하지 않는다.

- `zoom-150.png`: 합성 WebKit gesture로 150% 확대하고 하단 결과 상태 표시 옆 복귀 버튼 표시.
- `reset-100.png`: 결과 셀 안에서 ⌘0으로 정확히 100% 복귀한 상태.

버튼 클릭 후 셀 포커스와 방향키 이동, ⌘0 복귀를 앱에서 확인했다.
브라우저의 가상 결과 표는 양방향 스크롤 후 고정 버튼 위치, 클릭 및 Ctrl+0
복귀, focus 유지를 확인했다. 일반·가상 표를 함께 확대했을 때 각각의
하단 버튼이 자기 표만 초기화하고 상태 표시 없는 표는 하단 중앙 복귀 버튼을
표시함도 확인했다. 실제 macOS 트랙패드 확대·축소는 사용자 QA로
정상 동작 확인을 받았다. 스크린샷은 정식 배포나 모든 환경의 검수 증거는 아니다.
